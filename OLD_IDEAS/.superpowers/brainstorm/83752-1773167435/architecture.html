Session 1 Architecture

Decisions locked in. Here's how it all fits together.

The Core Structure

R3F canvas fills the full viewport via position: fixed. The HUD (top bar, left toolbar, right sidebar, bottom nav) is regular React DOM rendered on top via z-index. Zustand bridges them — a click in the 3D scene updates the store, the HUD components read it and re-render.

// page.tsx — the root
<div className="relative w-screen h-screen bg-[#060a12]">
<GalaxyCanvas /> ← R3F, position:fixed, z-0
<TopHUD /> ← regular React, z-10
<LeftToolbar /> ← regular React, z-10
<RightSidebar /> ← regular React, z-10
<BottomNav /> ← regular React, z-10
</div>

Zustand Store Shape

interface StellarStore {
// 3D scene
nodes: Node[]
selectedNodeId: string | null
zoomLevel: 1 | 2 | 3
cameraTarget: Vector3 | null
// HUD resources (computed from nodes)
cogBandwidth: { current: number; max: number }
resilience: number
focus: number
// Actions
selectNode: (id: string | null) => void
setZoomLevel: (level: 1|2|3) => void
setCameraTarget: (v: Vector3) => void
}
