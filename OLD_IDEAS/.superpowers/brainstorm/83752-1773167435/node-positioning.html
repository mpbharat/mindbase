How do the 8 domain nodes sit in the galaxy?

This decision affects the core 3D architecture. Choose what feels right.

A

Hardcoded Positions

Each of the 8 domains gets a hand-tuned x/y/z coordinate. You control exactly where everything is. Fast to implement.

  • Fast. Done in Session 1.
  • You curate the layout — looks intentional
  • Harder to change later (but we will)
B

Circular Orbit

All 8 nodes evenly spaced at equal distance. Like planets on the same orbit. Clean, symmetric, predictable.

  • Clean, mathematical, easy to code
  • Looks less organic / less Stellaris
  • Easy to add tilt/wobble for 3D feel
C

d3-force-3d (Recommended)

Physics simulation. Nodes repel each other, connections attract. They find their own natural positions. Truly organic layout — and it's in the spec.

  • Most organic — nodes cluster by connection strength
  • Matches the spec exactly (d3-force-3d)
  • Slightly more setup — worth it
  • Future: node importance changes = layout shifts
